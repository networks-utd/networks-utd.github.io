Data practices

Privacy notice

This notice describes the Colab Drive Access helper and its public information website.

Purpose and information accessed

The utility reads Google Drive file metadata and downloads selected research inputs. It creates new output files in the operator’s Drive. Only the operator’s own Google account is intended to authorize the app.

The drive.readonly permission allows reading existing files. The drive.file permission allows creating files and managing app-authorized files. The supplied helper has no deletion operation.

Use and transfer of files

Files transfer directly between Google Drive and the operator’s Google Colab runtime or local computer. Google hosts Drive and Colab. The helper adds no external file-storage or analytics service. Other tools the operator chooses to run have their own data practices.

The utility does not sell data, display advertisements, or use data to train an AI model. Running separate analysis or AI tools is outside this helper’s behavior.

The utility’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Credential storage

The reusable OAuth refresh credential is stored in the operator’s Colab Secrets. One-time desktop authorization also creates a local credential file outside the synced workspace; the operator can delete it after copying its contents into Colab Secrets.

Credentials are not included in notebook code or intentionally printed in its outputs. Code given access to a Secret can use that credential, so access should be enabled only for trusted notebooks.

Retention and removal

Downloaded files remain in the runtime until removed or the runtime is reset. Files uploaded to Drive remain there until the operator removes them.

The operator can revoke the app’s authorization using Google Account third-party access controls, remove the Colab Secret, and delete local copies.

This information website

This static website has no sign-in form, file uploader, advertising, or added analytics. It is hosted on GitHub Pages. GitHub may log technical request information, including IP addresses, for security purposes; see the GitHub Privacy Statement.
