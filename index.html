Colab Drive Access

Transfer research files between Google Drive and a Google Colab runtime, using a saved authorization.

This utility is operated by Sam Chen for personal research. It downloads selected inputs to a Colab runtime and uploads new result files to Drive through the Google Drive API.

A saved OAuth refresh credential lets the notebook renew authorization in later runtime sessions. The utility does not mount the entire Drive as a runtime folder.

Google Drive permissions

  • drive.readonly permits reading and downloading existing Drive files.
  • drive.file permits creating files and managing files authorized for this app. The supplied helper creates new output files and implements no deletion operation.

Only the operator’s own Google account is intended to authorize this utility. This website provides information about the app; it does not collect files or offer public account registration.

How files and credentials are handled

Files transfer directly between Google Drive and the operator’s Google Colab runtime or local computer. The reusable credential is stored in Colab Secrets and is kept out of notebook source and outputs.

This is a personal utility, not a university service. Google Drive and Colab retain their own terms and usage limits.
